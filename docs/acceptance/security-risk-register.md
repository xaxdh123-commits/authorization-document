# 安全风险登记

| 风险 | 当前控制 | 发布前动作 | 状态 |
|---|---|---|---|
| 普通电子签署证据能力有限 | Admin/H5 精确免责声明；保留未来第三方签名字段 | 后续接入可信时间戳、CA/司法存证 | 已接受（v1） |
| 恶意文件内容 | Magic bytes、扩展名/大小/数量/单业务容量限制、路径安全 | 生产接入杀毒/沙箱扫描 | P1 风险，尚未接入恶意软件扫描 |
| 链接泄露 | 32 字节随机令牌、仅存 SHA-256、过期/消费/关闭统一不可用 | 通过可信渠道发送；监控异常访问 | 已控制 |
| 敏感资料越权 | 普通入口遇敏感资料固定 403；单独 ability | 定期审计角色映射 | 已控制 |
| Token/连接串进入日志 | 响应不返回摘要字段；验收不得输出连接串 | 生产日志采集增加字段级脱敏规则 | 需运维复核 |
| NAS 不可用/路径穿越 | OS 挂载后使用 local 驱动；storage key 规范化与根目录隔离 | 上线前挂载健康文件、容量和权限检查 | 待目标环境验证 |
| v1 数据范围 | 明确不启用 SELF/DEPT/ALL 行级过滤，只保留字段 | 后期需求评审后另行实施 | 用户明确接受 |

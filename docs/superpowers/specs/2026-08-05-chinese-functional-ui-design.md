# 委托生产资料平台：中文功能界面补齐设计

日期：2026-08-05  
状态：用户已确认页面方向与实施范围

## 1. 目标

将中文设为后台与 H5 的默认、主要显示语言，并将需求文档中的首期功能完整呈现在前端页面中。本轮不是简单翻译现有骨架，而是建立完整中文信息架构，让所有首期功能都有明确入口、页面与状态反馈。

交付采用“完整功能可见 + 核心流程真实可用”的方式：业务单、客户 H5、审核、模板与资料配置接真实 API；可视化模板编辑器、PDF 预览和印章处理交付可操作、可保存的第一版，并保留后续生产级增强接口。

## 2. 设计原则

- 中文为主语言；用户可见标题、按钮、状态、错误、空状态和表单说明全部使用简体中文。
- 机器键、接口字段和模板变量保持稳定英文键，仅在配置页面显示中文名称与机器键映射。
- 后台采用已确认的 A 方案：左侧完整导航、顶部工具栏、主内容区。
- 页面入口完整，但首期不制造“假完成”：未接生产能力的高级功能应明确标注为第一版能力。
- 授权书始终为系统必选资料，其他凭证由客服按业务单选择。
- 角色及页面能力继续依据上游 `getInfo` 的 `roles[].roleKey` 与权限摘要判断。

## 3. 后台信息架构

### 3.1 工作台

- 状态统计：草稿、待客户填写、客户填写中、待审核、需补件、待复审、待生成 PDF、已完成。
- 待办事项、最近业务单、超期业务单。
- 快捷操作：新建业务单、进入审核队列、创建模板。

### 3.2 业务单管理

- 业务单列表：按编号、客户、工厂/部门、负责人、状态、日期筛选。
- 新建业务单：委托方、联系人、受托方/工厂部门、报价来源、多个物料明细、模板、资料要求。
- 业务单详情包含七个标签：基本信息、物料明细、客户问卷、资料文件、授权书、审核记录、操作日志。
- 右侧流程区显示客户链接、有效期、访问状态、最近保存时间与流程时间线。
- 客户链接操作：复制、续期、停用、重新生成；完成后自动关闭。

### 3.3 审核中心

- 待审核队列与我的审核。
- 支持领取、逐项通过、填写驳回原因、要求补件、复审和最终确认。
- 驳回最小粒度为资料项；其他已通过项目保持只读。
- 最终确认后进入 PDF 生成状态；生成失败可重试。

### 3.4 配置中心

- 资料项配置：中文名称、说明、字段类型、允许文件类型、大小、数量、必填、排序、启停用与版本。
- 授权书模板：列表、复制、草稿、发布、停用和版本历史。
- 模板编辑器：组件栏、A4 画布、属性栏三栏布局。
- 编辑器首版组件：标题、正文、图片、表格、分页符、物料循环表格、动态变量、签名/印章位置。
- 动态变量分为客户、业务单、物料、系统日期和问卷字段；显示中文名称并保存稳定机器键。

### 3.5 系统管理

- 角色权限映射：上游 `roleKey` 映射管理员、客服、审核员能力及 SELF/DEPT/ALL 数据范围。
- 操作审计日志：操作人、时间、对象、动作、前后状态、结果与备注。
- 系统设置：上游鉴权地址、文件目录、H5 主域、链接有效期、签署模式与 PDF 设置。

## 4. 客户 H5

H5 全部使用简体中文，采用四步流程：

1. 确认信息：委托方、受托方、联系人及物料快照。
2. 填写与上传：根据业务单资料要求生成动态问卷和文件上传控件。
3. 预览与签署：预览授权书，选择手写签名或上传印章图；印章首版支持背景去除预览和位置覆盖。
4. 确认提交：真实性与授权意愿声明、提交结果和只读完成页。

H5 从随机不可猜测令牌加载业务单，支持 URL 与 localStorage 草稿恢复。驳回后使用原链接进入补件模式，只开放被驳回资料项；全部完成后链接失效。

## 5. 数据与接口流

### 5.1 后台鉴权

后台携带现有系统 Token，请求平台 `auth/getInfo` 兼容入口；平台可代理上游鉴权。前端根据角色和权限显示导航，后端仍执行权限与数据范围校验。

### 5.2 业务单

后台加载模板与资料项目录，创建业务单时保存模板版本、资料版本、报价信息和物料快照。创建成功后返回业务单编号、客户令牌和截止时间。

### 5.3 H5 草稿与提交

H5 使用令牌读取公开业务单视图，按版本号自动保存草稿。发生版本冲突时提示加载服务器版本或保留本地副本。正式提交后转入待审核，普通页面只读。

### 5.4 文件、签署与 PDF

文件写入本地存储适配器，后续可将根目录挂载 NAS。签名或透明印章资源保存独立版本并记录摘要。模板预览与最终 PDF 通过 Worker 生成；第一版普通签署保留第三方可信签署模式字段。

## 6. 状态与错误处理

- 所有状态使用统一中文映射，不直接展示内部枚举。
- 页面包含加载中、空数据、无权限、链接无效/过期、保存失败、上传失败、冲突、PDF 失败等中文反馈。
- 驳回原因必填；完成前检查所有资料项已通过、签署声明存在、签章位置合法。
- 客户链接无效、过期和关闭使用统一页面，避免泄露业务单是否存在。

## 7. 实施分层

### 7.1 接真实接口

- 中文后台框架与完整导航。
- 工作台、业务单列表/新建/详情、客户链接管理。
- H5 动态资料、草稿、上传、普通签署和提交。
- 审核队列、逐项审核、驳回补件与复审。
- 资料项和模板目录管理。
- 角色映射、审计日志基础查询、系统设置读取。

### 7.2 可操作第一版

- 可视化模板编辑器及 JSON AST 保存。
- A4 预览、变量插入、物料循环表格与签章占位。
- 手写签名画板、上传印章、背景去除预览与位置调整。
- PDF 预览和生成任务状态。

## 8. 测试与验收

- 所有主要页面以中文渲染，不出现未翻译的英文标题、按钮、状态或错误。
- 管理员可从左侧导航进入所有需求功能页面。
- 客服可创建包含多个物料和可选资料的业务单并复制客户链接。
- H5 可完成四步流程，刷新后恢复草稿，驳回后仅编辑指定项目。
- 审核员可逐项通过或驳回，驳回原因必填，复审记录可查询。
- 模板编辑器可保存、重新打开、插入变量和签章占位，并生成预览。
- 权限、过期令牌、文件限制、冲突和 PDF 失败均有自动化测试与中文错误反馈。
- 全仓 typecheck、test 和 build 必须通过。

## 9. 非本轮生产级范围

- 第三方可信电子签约、实名认证、CA 证书、可信时间戳与证据报告。
- 与报价系统数据库/API 的正式自动导入；本轮保留人工输入、URL 和 localStorage 传参。
- 复杂 Word 级排版、多人会签和微服务化部署。

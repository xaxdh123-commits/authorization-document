# 委托生产资料平台：中文功能界面补齐设计

日期：2026-08-05  
状态：用户已确认页面方向与实施范围

## 1. 目标

将中文设为后台与 H5 的默认、主要显示语言，并将需求文档中的首期功能完整呈现在前端页面中。本轮不是简单翻译现有骨架，而是建立完整中文信息架构，让所有首期功能都有明确入口、页面与状态反馈。

交付采用“完整功能可见 + 核心流程真实可用”的方式：业务单、客户 H5、审核、模板与资料配置接真实 API；可视化模板编辑器、PDF 预览和印章处理交付可操作、可保存的第一版，并保留后续生产级增强接口。

## 2. 设计原则

- 中文为主语言；用户可见标题、按钮、状态、错误、空状态和表单说明全部使用简体中文。
- 机器键、接口字段和模板变量保持稳定英文键，仅在配置页面显示中文名称与机器键映射。
- 后台采用已确认的 A 方案：左侧完整导航、顶部工具栏、主内容区。
- 页面入口完整，但首期不制造“假完成”：未接生产能力的高级功能应明确标注为第一版能力。
- 授权书始终为系统必选资料，其他凭证由客服按业务单选择。
- 角色及页面能力继续依据上游 `getInfo` 的 `roles[].roleKey` 与权限摘要判断。

## 3. 后台信息架构

### 3.1 工作台

- 状态统计：草稿、待客户填写、客户填写中、待审核、需补件、待复审、待生成 PDF、最终文件生成失败、已完成、已关闭。
- 待办事项、最近业务单、超期业务单。
- 快捷操作：新建业务单、进入审核队列、创建模板。

### 3.2 业务单管理

- 业务单列表：按编号、客户、工厂/部门、负责人、状态、日期筛选。
- 新建业务单：委托方、联系人、受托方/工厂部门、报价来源、多个物料明细、模板、资料要求。
- 业务单详情包含七个标签：基本信息、物料明细、客户问卷、资料文件、授权书、审核记录、操作日志。
- 右侧流程区显示客户链接、有效期、访问状态、最近保存时间与流程时间线。
- 客户链接操作：复制、续期、停用、重新生成；完成后自动关闭。

### 3.3 审核中心

- 待审核队列与我的审核。
- 支持领取、逐项通过、填写驳回原因、要求补件、复审和最终确认。
- 驳回最小粒度为资料项；其他已通过项目保持只读。
- 最终确认后进入 PDF 生成状态；生成失败可重试。

### 3.4 配置中心

- 资料项配置：中文名称、说明、字段类型、允许文件类型、大小、数量、必填、排序、启停用与版本。
- 授权书模板：列表、复制、草稿、发布、停用和版本历史。
- 模板编辑器：组件栏、A4 画布、属性栏三栏布局。
- 编辑器首版组件：标题、正文、图片、表格、分页符、物料循环表格、动态变量、签名/印章位置。
- 动态变量分为客户、业务单、物料、系统日期和问卷字段；显示中文名称并保存稳定机器键。

### 3.5 系统管理

- 角色权限映射：上游 `roleKey` 映射管理员、客服、审核员能力及 SELF/DEPT/ALL 数据范围。
- 操作审计日志：操作人、时间、对象、动作、前后状态、结果与备注。
- 系统设置：上游鉴权地址、文件目录、H5 主域、链接有效期、签署模式与 PDF 设置。

权限基线如下：管理员拥有全部能力和 `ALL` 数据范围；客服可在 `SELF` 范围创建、编辑未提交业务单、管理客户链接和查看普通资料；审核员可在 `DEPT` 范围领取未分配任务、查看已分配任务、逐项审核、驳回、复审和重试 PDF。敏感资料查看为独立能力，客服默认没有法人身份证等敏感资料下载权限。多角色取能力与数据范围并集，未配置角色默认拒绝进入平台。所有查看、下载、审核、关闭、模板发布、角色配置和审计日志接口必须在服务端校验能力与 `SELF/DEPT/ALL` 范围，越权统一返回 403。

审核任务首次提交后进入负责部门未分配队列；审核员通过原子操作领取，避免多人同时占用。管理员可分配或改派任意非终态任务；拥有目标部门范围的客服只可在本部门改派负责人；审核员不能自行改派。领取、分配与改派均写入审计日志。

## 4. 客户 H5

H5 全部使用简体中文，采用四步流程：

1. 确认信息：委托方、受托方、联系人及物料快照。
2. 填写与上传：根据业务单资料要求生成动态问卷和文件上传控件。
3. 预览与签署：预览授权书，选择手写签名或上传印章图；印章首版支持背景去除预览和位置覆盖。
4. 确认提交：真实性与授权意愿声明、提交结果和只读完成页。

H5 从随机不可猜测令牌加载业务单，支持 URL 与 localStorage 草稿恢复。驳回后使用原链接进入补件模式，只开放被驳回资料项；全部完成后链接失效。

H5 和后台签署区域必须显示：“当前为普通电子签署，不等同于第三方可靠电子签名。”界面不得使用实名认证、CA、可信时间戳或法律认证等暗示。印章自动去背景失败时保留原始文件，不覆盖原图，并允许重新上传或改用手写签名。

## 5. 数据与接口流

### 5.1 后台鉴权

后台携带现有系统 Token，请求平台 `auth/getInfo` 兼容入口；平台可代理上游鉴权。前端根据角色和权限显示导航，后端仍执行权限与数据范围校验。

鉴权成功要求上游 HTTP 200、业务 `code = 200`、存在 `user.userId` 且至少一个有效 `roles[].roleKey`。上游 401/403 或业务返回未登录/过期时，平台清除会话摘要并返回统一 401；超时、网络错误、5xx 或不可解析响应返回 503，并显示“认证服务暂不可用，请稍后重试”。默认超时 3 秒，成功结果仅按 Token 摘要缓存最多 60 秒，不保存原 Token。缓存过期且上游不可用时拒绝所有写操作；仍在 60 秒有效缓存内仅可按原权限执行读操作。

### 5.2 业务单

后台加载模板与资料项目录，创建业务单时保存模板版本、资料版本、报价信息和物料快照。创建成功后返回业务单编号、客户令牌和截止时间。

报价系统接入首版支持人工输入/复制，以及安全的同源页面交接。URL 只允许报价单编号、来源类型和一次性短期交换令牌，不允许传客户资料、价格、证件或完整报价 JSON。`localStorage` 仅允许同源场景暂存非敏感表单草稿，读取后立即删除；跨子域不依赖普通 localStorage。未来正式跨系统接入使用一次性交换令牌，由后端换取报价快照并立即失效。

### 5.3 H5 草稿与提交

H5 使用令牌读取公开业务单视图，按版本号自动保存草稿。发生版本冲突时提示加载服务器版本或保留本地副本。正式提交后转入待审核，普通页面只读。

草稿保存携带版本号；服务器版本不一致返回 409。客户端保留未提交内容，但不自动合并、不静默覆盖。用户可先查看服务器最新版后重新填写，或明确确认“用本地内容创建新版本”；多窗口冲突必须以端到端测试覆盖。

### 5.4 文件、签署与 PDF

文件写入本地存储适配器，后续可将根目录挂载 NAS。签名或透明印章资源保存独立版本并记录摘要。模板预览与最终 PDF 通过 Worker 生成；第一版普通签署保留第三方可信签署模式字段。

存储键和磁盘文件名由服务端随机生成，不使用上传原名拼接路径。上传同时校验扩展名、声明 MIME 与真实文件特征，限制单文件大小、文件数量和单业务单总量；拒绝路径穿越、双扩展名和超限文件。下载必须重新校验能力、数据范围和敏感资料权限；响应和日志不得暴露磁盘路径、原 Token、完整证件号或敏感文件内容。首版未交付恶意文件扫描时，文件一律以附件下载、不得在服务器或浏览器环境直接执行，并在上线检查中明确风险。

回答、文件、签署和审核每次修改均创建不可变版本。业务单详情对应标签提供版本时间线；具备权限的用户可查看和下载补件前后的历史版本。业务当前视图只指向最新有效版本，历史记录不得覆盖或删除。

完整状态流为：`草稿 → 待客户填写 → 客户填写中 → 待审核 → 需补件 → 待复审 → 待生成最终文件 → 已完成`，另有 `待生成最终文件 → 最终文件生成失败 → 待生成最终文件` 重试分支，任一非终态可按权限进入 `已关闭`。全部资料审核通过后冻结客户编辑并进入待生成状态。只有 Worker 成功生成最终 PDF、文件可读取且 SHA-256 与数据库记录一致时，才原子进入已完成并关闭客户链接；失败进入独立失败态，客户继续冻结，管理员或审核员可重试。

模板发布版本不可修改，业务单固定引用具体版本和渲染快照。发布前必须校验变量存在且未停用、变量类型匹配组件、必填变量有来源、签章位页码/尺寸/锚点合法、多物料变量只用于循环表格；任何失败均禁止发布并给出中文定位信息。

## 6. 状态与错误处理

- 所有状态使用统一中文映射，不直接展示内部枚举。
- 页面包含加载中、空数据、无权限、链接无效/过期、保存失败、上传失败、冲突、PDF 失败等中文反馈。
- 驳回原因必填；完成前检查所有资料项已通过、签署声明存在、签章位置合法。
- 客户链接无效、过期和关闭使用统一页面，避免泄露业务单是否存在。

## 7. 实施分层

### 7.1 接真实接口

- 中文后台框架与完整导航。
- 工作台、业务单列表/新建/详情、客户链接管理。
- H5 动态资料、草稿、上传、普通签署和提交。
- 审核队列、逐项审核、驳回补件与复审。
- 资料项和模板目录管理。
- 角色映射、审计日志基础查询、系统设置读取。
- 模板目录的草稿、复制、发布、停用、版本历史全部使用真实写接口和持久化记录。

### 7.2 可操作第一版

- 可视化模板编辑器及 JSON AST 保存。
- A4 预览、变量插入、物料循环表格与签章占位。
- 手写签名画板、上传印章、背景去除预览与位置调整。
- PDF 预览和生成任务状态。

上述第一版能力不是纯前端演示：编辑器 AST、签章资源、位置和任务状态均通过真实 API 保存；模板草稿可重新打开。第一版编辑器生成的已发布模板可以被真实业务单引用，并进入预览/最终 PDF 流程。印章自动去背景采用基础算法，质量不足时必须由客户确认或重新上传。首版不承诺 Word 级排版、复杂图片识别或可靠电子签名法律能力。

## 8. 测试与验收

- 所有主要页面以中文渲染，不出现未翻译的英文标题、按钮、状态或错误。
- 管理员可从左侧导航进入所有需求功能页面。
- 客服可创建包含多个物料和可选资料的业务单并复制客户链接。
- H5 可完成四步流程，刷新后恢复草稿，驳回后仅编辑指定项目。
- 审核员可逐项通过或驳回，驳回原因必填，复审记录可查询。
- 模板编辑器可保存、重新打开、插入变量和签章占位，并生成预览。
- 权限、过期令牌、文件限制、冲突和 PDF 失败均有自动化测试与中文错误反馈。
- 全仓 typecheck、test 和 build 必须通过。

验收使用固定测试数据：1 个管理员、1 个 `SELF` 客服、1 个 `DEPT` 审核员、1 个 `ALL` 管理员；1 套已发布模板；3 个资料项；2 条和 20 条物料两组业务单。主要页面清单为工作台、业务单列表/新建/详情七标签、审核队列/详情、资料项配置、模板列表/编辑器、角色映射、审计日志、系统设置，以及 H5 四步、补件、链接失效页面。除机器键、模板变量、文件扩展名和技术摘要外，不得出现英文用户文案。

权限用例覆盖查看、下载、敏感文件下载、领取竞争、审核、关闭、模板发布、角色配置和审计日志；允许返回 2xx，越权固定返回 403。令牌用例覆盖有效、过期、停用、重新生成后旧令牌失效，状态变化在 1 秒内生效。上传用例覆盖刷新恢复、断点失败重试、扩展名/MIME 不一致、路径穿越、单文件与总量超限。PDF 用例覆盖 API/Worker 重启恢复、失败重试、最终文件 SHA-256 一致，以及固定测试数据下预览与最终 PDF 的关键文本、物料行数和签章外接矩形一致。

补件用例要求驳回 3 个资料项中的 1 项后，仅该项可编辑，另外 2 项保持只读；补件前后回答、文件、签署和审核版本均可按权限查询下载。草稿冲突用例要求第二窗口收到 409，本地内容不丢失，且未确认前不能覆盖服务器版本。

## 9. 非本轮生产级范围

- 第三方可信电子签约、实名认证、CA 证书、可信时间戳与证据报告。
- 与报价系统数据库/API 的正式自动导入；本轮保留人工输入/复制、非敏感引用参数和同源非敏感草稿，敏感跨系统数据使用未来的一次性交换令牌方案。
- 复杂 Word 级排版、多人会签和微服务化部署。

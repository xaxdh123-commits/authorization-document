# 故障恢复运行手册

1. 宣告事故并冻结写入，记录最后正常业务版本和 PDF 任务游标。
2. 在独立网络和独立凭证下创建以 `_recovery_drill` 结尾的数据库。
3. 校验备份 SHA-256 后恢复数据库与文件到 `RECOVERY_DRILL_ROOT` 下的不同目录。
4. 核验业务单、资料版本、签署记录、审计记录和最终 PDF 哈希；禁止直接覆盖生产目录。
5. 在隔离环境启动 API/Worker，确认未完成 PDF 可恢复且不会生成重复最终记录。
6. 记录实际备份年龄和恢复耗时；RPO >24h 或 RTO >8h 时发布门禁失败。

任何真实恢复、PM2 重启或流量切换均需变更审批。本地验收只执行 `recovery-drill.ps1 -ValidateOnly`。
